HTML LISTS

I learnt three main types of HTML lists. An ordered list uses <ol> when the order matters. An unordered list uses <ul> for bullet points. A descriptive list uses <dl>, with <dt> for a term and <dd> for its description.

I practised using lists for favourite foods, ingredients, and cooking steps. I also learnt that block-level and inline elements behave differently on a page and that attributes provide extra information about an element.
