HTML LISTS

An ordered list (<ol>) is for items whose sequence matters. An unordered list (<ul>) is for a group where sequence does not matter. Each uses <li> for its items. A description list (<dl>) pairs terms in <dt> elements with explanations in <dd> elements.

Lists can be nested to show sub-items. Use the list type that matches the information, not just the marker style. Attributes such as start and reversed can change an ordered list.

For the food assignment, list favourite foods with <ol>, ingredients with <ul>, and preparation steps with <ol> and <li>. Use a description list when presenting terms and their explanations. The separate block-level and inline-element research task is about how elements participate in page layout; it is not another list type.
